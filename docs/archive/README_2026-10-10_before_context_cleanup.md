# Indus script: reproducible investigation

**Status: structural findings and testable partial hypotheses; no demonstrated decipherment.**

This project audits the supplied 417 Mahadevan-style sign images, adds versioned
inscription corpora and comparison data, and tests what can actually be inferred.
It does not assign invented words or sounds to unexplained signs.

**Current track (10 October): build a complete, consecutive-page M77 corpus.**
The current release covers 122 references and 132 printed lines. An alternative
scan resolved three glyph ambiguities; source-marked doubt and damaged spans
remain. This verifies transcription against M77's printed pages, not against
ancient objects. Individual artifact searches have stopped.

## Reproduce

Python 3.10+; sequence analysis uses the standard library. Image auditing additionally
needs NumPy and Pillow. The original inputs are left untouched.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/run_all.py
```

The raw inputs are already saved. `run_all.py` verifies downloaded checksums and
works offline. If a raw download is missing, `python3 scripts/fetch_data.py` fetches
the pinned source and checks its hash before saving. Unchanged reruns overwrite only
generated results. Runtime versions from the completed run are in
[`results/run_manifest.json`](../../results/run_manifest.json).

Archived error responses and bounded web-text captures are checksum-verified but
not automatically re-fetched. A web capture is labeled separately from original
PDF bytes; its source URL and retrieval method remain in the source registry.

All downloaded research files are kept together in `data/raw/`, including unused
discovery files and archived error responses. Keep future downloads in that same
folder and record their provenance in `data/sources.json`.

Maintain `docs/RESEARCH_LOG.md` as the continuing research record. Append each
substantive hypothesis test, source search, negative result and correction, with
its method, outcome, limitations and evidence paths. Preserve failed predictions;
label retrospective backfill and post-result rule changes explicitly. Update the
log before closing a research phase and refresh `results/run_manifest.json`.

For a structural suggestion about a single missing sign:

```sh
python3 scripts/suggest_sign.py 'W740 ? W033'
```

This returns ranked signs, **not a translation**. Use Wells/ICIT codes and the source
CSV's order. Do not substitute Mahadevan numbers. All matching masked texts and their
connected artifact groups are excluded from training.

## Repository layout

| Path | Purpose |
|---|---|
| `IM_417_150_PNG/`, `im_417_150.csv` | Original user-supplied images and pixels |
| `data/raw/` | Frozen downloaded corpora; original source claims retained |
| `data/sources.json` | URLs, revisions, SHA-256 hashes, provenance caveats |
| `data/processed/` | Strict transcriptions, comparison corpora, candidate crosswalk |
| `scripts/` | Data retrieval, audits, inference, controls, sign suggestions |
| `results/` | Statistics, exclusion ledgers, predictions, all-sign dossiers, atlas |
| `tests/` | Scientific-validity checks for parsing, grouping, and statistics |
| `docs/` | Interpretation, proof scope, source references, future tests |

The secondary `lipi` export contains proposed Sanskrit readings. **Those columns are
never imported into analysis.** Its canonicalization table is not used. Raw source
retention is for auditing and is not endorsement or a grant of redistribution rights.

This is local research; nothing has been published or sent to others.
