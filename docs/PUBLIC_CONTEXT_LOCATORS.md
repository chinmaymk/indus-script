# Provisional public-context locators

11 October 2026. **627 provisional locators, not 627 authenticated artifact joins.**
The frozen metadata pass finds four repeated complete raw locus/depth tuples.
It establishes no depositional units, independent contrasts, sounds or meanings.

Three individually documented field-to-Mackay associations motivated one literal
candidate rule: uppercase and remove whitespace from `field_no` and Mackay `no`,
concatenate those strings, and compare to the unaltered Lipi excavation string.
This is an exploratory locator, not a validated global parsing rule. The prior
strict-field profile remains preserved with zero matches; its rule was different.
The new [protocol](../data/processed/public_context_locator_protocol_v1.json) was
frozen before full locator counts and reviewed independently before execution.

The one pass rejects missing components, concatenation collisions, nonunique
table field keys, keys shared across artifacts, artifact field conflicts and
nonexclusive Mohenjo-daro sites. Repeated inscription rows remain witnesses,
never additional objects. Five adversarial tests cover boundary collisions,
duplicates, cross-row conflicts, raw datum separation and literal preservation.
No sign, proposed reading, translation or inferred phase is imported.

Post-run independent review verified the projected source fields, every key,
witness and exclusion reason, and all counts. A separate
[audit manifest](../results/public_context_locators_v1_review.json) pins the
imported metadata helpers omitted from the original result manifest; the frozen
result itself is unchanged.

Tuple equality alone says nothing about shared deposition, contemporaneity,
original use, artifact dependence or a linguistic category. The 627 candidates
have not been substituted into the source corpus or a contextual significance
test. Independence is not acquired by linking another description of an object.
