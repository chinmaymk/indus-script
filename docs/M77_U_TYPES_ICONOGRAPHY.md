# Primary object types for the 5000-series M328 references

Reviewed 2026-09-23. All **100 unique references** selected by `5000 <= reference < 6000` from the recovered-M328 line ledger have a readable object-type digit in Mahadevan's primary *Texts* metadata. The result is **1 seal, 37 sealings and 62 miniature tablets**; none remains unverified.

| Primary type code | Category | Verified references |
|---|---|---:|
| 1 | Seals | 1 |
| 2 | Sealings | 37 |
| 3 | Miniature tablets: stone, terracotta or faience | 62 |

The sole seal is **5077**, with printed code `5077 100101`, PDF142/printed131. The 37 selected sealing references begin with 5222 and 5223, each printed `210001`, PDF144/printed133; their second-side stroke-plus-U texts therefore belong to objects catalogued as sealings. The selected miniature-tablet references begin with 5402, printed `310002`, PDF150/printed139. These ranges describe the observed result; they were not used to infer type. Every selected reference's own first-line code was read.

The [structured ledger](../data/processed/m77_u_types_iconography.json) preserves each literal reference-plus-six-digit code, fifth-digit object type, PDF and printed page, first-line side and line, verification status and image SHA-256. No glyph transcription was needed for this task. The selected objects occupy PDF142,144,146–156; PDFs143 and145 were checked during location and contain no selected references.

The primary codebook (PDF30/printed19, section12.2) defines ten columns: four reference digits, object type, side, two field-symbol digits, line and direction. The category labels come from PDF41/printed30. This review used those primary definitions and full-page renders, without reading candidate-export metadata. All codes were legible; literal differences such as `5302 219101`, `5337 213702`, `5444 319101`, `5472 319301`, `5483 319309`, `5484 318301` and `5496 313701` are retained.

The first metadata line is not necessarily the U-bearing line. Its direction digit must **not** be assigned to every side or line. The ledger's first-line side/line fields identify the inspected row; only the object's type transfers across its lines. Likewise, code3 groups three materials and does not identify a manufacturing technique, mold or particular material.

This authenticates Mahadevan's catalogue classifications, not fresh material identifications from photographs. It establishes that selected M328 inscriptions occur on multiple recorded object categories; it does not by itself establish what M328 means.

Validation confirmed exact coverage of the100 selected references, unique keys, ten metadata digits per row, consistency of type/side/line extraction, and all source/render hashes. No downloads or shared-registry edits were made.
