# Fish and stroke variants behind the roof comparison

27 September2026. **The inspected base variants remain unroofed, but their internal
geometry is not fixed by the catalogue code.** This supports retaining the broad
roof/no-roof question while limiting any exact graphical decomposition to checked
glyphs. It does not identify the roof's function or establish an allograph relation
between a base and a roofed code.

The parent inspected the retained M77 AppendixI at printed786/PDF795 and its
addendum at printed792/PDF801. The addendum matters: M059's variant entry is there,
not between57 and60 on printed786. Numbers below drawings are source inscription
references, not occurrence counts or alternate sign numbers.

| Code and source references | Direct observation |
|---|---|
| M059:1032,8211 | Both have an oval upper body and crossed lower strokes, without a roof. The1032 drawing has lateral projections at the body/tail junction;8211 omits those projections. |
| M060:1177,7025 | Both have the fish-shaped body and four flanking marks, without a roof. The first uses short upright strokes; the second uses dots. |
| M089:1003,2573 | Both have three parallel strokes and no roof. The first is upright; the second is slanted. Their count is a visual property, not a deciphered numeral. |

The [M059 crop](../results/primary_pages/roof-variants-M059.png),

The original representative M065 andM066 drawings add a shallow apex-up roof to
a fish-shaped body retaining lateral projections; M092 places a roof above three
upright strokes. These selected drawings remain useful comparisons. They do not
license substituting exactly the same base outline for every occurrence of059,
060 or089, nor prove that every listed unroofed variant has a corresponding roofed
variant. No observed roofed counterpart to the armless8211 variant was authenticated
in this bounded inspection. That is missing evidence, not proof it never existed.

The broad roof state does not change for any of the six inspected base drawings.
Thus this review does not supply a recoding of the prior context screen. The more
specific claim that each code is one invariant geometric base is too strong.
Likewise, equivalence classes defined by an editor cannot independently establish
that their members had the same ancient sound or meaning.

M059 appears in the final addendum introduced by the book's postscript; absence
from the main ordered section is not absence of variants. The complete addendum
column was visually inspected: no further entry for the six candidate pair endpoints
appears there beyond059. This statement concerns that column, not every original
inscription, unpublished variant or the full variant list's non-target signs.
