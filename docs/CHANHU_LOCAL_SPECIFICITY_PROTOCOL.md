# Does the five-seal contrast distinguish the fish-like sign?

28 September 2026. The preceding turn was progress: it produced a complete
65-entry illustrated frame, a conditional local contrast and an archival lead.
This phase checks graphic authentication and specificity. Its control analysis
is retrospective: the five selected artifacts and target outcomes are already
known. It is not a new workshop test, held-out prediction or decipherment.

Keep the previous five artifact identities and area labels unchanged. Use the
same 65-entry primary frame. The 55 accepted metadata joins supply secondary
texts; all ten unresolved joins have unknown text for every candidate. Do not
silently substitute a same-plate/different-number candidate. Subtract the five
selected artifacts to obtain a 60-object external-frequency background. It is
external to this small contrast, not an independent excavation or validation set.

The main specificity target is singleton **W220**, not a pooled family compared
unfairly to individual signs. Keep the existing full-family result separately.
The control universe is every certain three-digit W code observed in an accepted
background text, excluding placeholders W000/W999 and codes mapped to catalogue
P050–P065, plus W221. Call the remainder **non-target controls**; this exclusion
does not independently authenticate the shapes or meanings of every code.

For each candidate, apply the existing certain-positive / complete-absent /
otherwise-unknown rule without alteration. Preserve unjoined primary objects as
unknown. Report each candidate's background positive, absent and unknown counts.
The strict frequency-matched set requires the same certain-positive count as
W220. A second set also requires equal unknown count. A declared wider sensitivity
allows certain-positive counts between half and twice W220's count, inclusive.
These are observed-frequency matches, not assumed equality of true frequencies;
report missingness instead of inventing imputed frequencies. If the target has
no background positives, the wider set is unavailable rather than arbitrarily
expanded.

Only after those background sets are fixed, calculate each control's five-object
statuses and exact area-difference bounds using the same formula as the target.
Report equal five-object status profiles, equal intervals, and lower bounds
at least as large as the target's, with strictly larger lower bounds counted
separately. Report interval width; a larger upper bound can merely reflect more
ignorance and is not stronger evidence. Include the full control
table, not just favorable examples. Count distinct profiles as well as codes:
several codes on one seal are not independent replications.

No ranks are p-values; codes are not independent, and frequency matching does
not equalize position, length, production, phase, preservation or publication.
A tied or stronger control would show that this particular contrast does not
uniquely select W220. No such control would still not establish a fish/gemstone
meaning, given one area block per category and uncertain archaeological joins.
The all-sign inventory remains unassigned. Independent primary-photo reviews
are a separate layer; any revised status must be reported as a sensitivity,
never silently substituted into the frozen calculation.
