# Non-quantity alternatives for the stroke-plus-U field

The matched two/three/four-stroke examples establish a varying graphic field, not its meaning. **Literal duplication alone cannot erase that variation.** A production-lot mark, categorical label or context-dependent allograph remains possible, but becomes a useful hypothesis only when its conditioning variable is established independently of the stroke count. The current records do not establish mold, engraver, narrow production date or represented amount for the three matched tablets.

This is an exploratory challenge to the quantity interpretation, using the existing primary recovery in [M77_U_FIELDS](M77_U_FIELDS.md). No p-value or corpus prevalence is inferred from sorted concordance pages. The [machine-readable review](../data/processed/m77_u_alternatives.json) retains source provenance, exact tested records and predictions.

**Subsequent evidence:** [the exact artifact bridge](M77_U_ARTIFACT_BRIDGE.md)
has since established steatite material for all three, an oval shape for the
two-stroke example, rectangular shapes for the others, and different nominal
dimensions and find contexts. The initial unknowns below describe this review's
input state. A rule using material alone now also fails for this trio; independently
identified molds, tooling and production dates remain unavailable.

## What repetition can explain

Kenoyer and Meadow distinguish copied incised inscriptions from molded duplicates. They also report the same sequences on different molds, so a normalized text match does not establish a mold match. Their 2010 discussion describes 22 incised copies and a separate set of 31 molded duplicates, while noting that these assemblages were recovered in secondary deposits. Their purpose remains uncertain. These observations make manufacturing dependence a real concern without identifying the manufacture of our selected M77 objects. [Kenoyer & Meadow 2010, PDF pp.6–7](https://www.harappa.com/sites/default/files/pdf/KenoyerMeadow%202010%20Inscribed%20Objects%20from%20Harappa.pdf).

In the 2000 report, microscopic study attributed a 22-tablet set bearing the same inscriptions to at least three engravers. Side arrangement and orientation varied. The authors allow either concurrent manufacture or accumulation from multiple episodes; their discussion of validity and eventual discard is explicitly interpretive. A shared deposited cluster is consequently neither one hand nor necessarily one manufacturing event. These later excavated tablets are comparative evidence, **not** a demonstrated join to M77 references 4508, 4509 or 4548. [Meadow & Kenoyer 2000, PDF pp.14–18](https://www.harappa.com/sites/default/files/pdf/Kenoyer2000_The%20Tiny%20Steatite%20Seals%20of%20Harappa.pdf).

## Tests possible with the recovered records

I independently grouped the reviewed pairs by exact main and auxiliary strings, collapsing repeated identical pairs. Nine selected reference records reduce to seven distinct paired patterns:

| Main string | Auxiliary states retained after collapsing identical pairs |
|---|---|
| M048 M342 M176 | M087 M328: 4548/5464; M089 M328: 4509/4387; M095 M328: 4508 |
| M391 M099 M040 | M087 M328: 4665; M089 M328: 4601 |
| M175 M176 M211 M176 | M087 M328: 5270; M089 M328: 4684 |

This is **text-pattern deduplication**, not archaeological mold deduplication. It preserves all three graphic states of the first main pattern even when repeated instances of the same pair receive only one vote. The count difference is therefore not created solely by counting copies many times.

For the strongest triad, the separately checked original Texts metadata assigns all three references 4548/4509/4508 to object code 3 (miniature tablets), side 1 and side 2, one line per side, with original RTL direction on both sides. A deterministic account based only on main text, that coarse object type and those directions fails: its inputs are the same but its auxiliary state differs. Material, tooling, dimensions, mold identity and tight chronology were **not** controlled by this test. Object code 3 includes stone, terracotta and faience; it does not mean “same mold.”

A fixed, unchanged whole-object mold that leaves every stroke legible predicts identical graphic counts in its faithful products. The triad cannot all be faithful duplicates of one such unchanged complete template, conditional on the primary drawings being accurate. This does not rule out different molds, interchangeable side molds, recutting, hand copying or damaged impressions. None of those mechanisms is established for the exact triad here.

## Specific alternatives and discriminating observations

| Restricted hypothesis | Prediction fixed before further inspection | Current result and possible falsifier |
|---|---|---|
| **Production-lot label:** one auxiliary state per independently identified production lot | Within a lot identified blind from clay/stone composition, tool marks and secure production context, newly examined tablets have the same state even when main text differs | Not tested for the triad. Two clearly distinct states within one such lot falsify the *constant-lot* version. Calling each observed state its own lot is circular. |
| **Mold-family or engraver convention:** stroke groups are stylistic variants | Geometry or tool-mark groups assigned without seeing the auxiliary count predict its form on withheld objects; no systematic relation to an independently measured amount is required | Not established. The published 22-copy set shows that identical inscriptions can cross engraver groups; it rejects a universal one-to-one equation of inscription and engraver, not every hand-conditioned rule. Counts alone cannot identify hands. |
| **Category label:** the auxiliary state marks a non-amount class | Classes must be observable independently—for example material recipe, shape or distribution context—and the fixed class-to-state rule transfers to withheld tablets and main strings | A rule based only on the tested main string/coarse tablet type/direction is contradicted. Finer independently defined classes remain untested. Classes defined as “the two-stroke class” explain nothing. |
| **Chronological style:** one graphic form replaces another in a specified production interval | Secure production strata show the predicted ordering across different main strings, using dates/bins chosen independently of stroke states | Not tested. A sealed contemporary manufacturing assemblage containing all forms would contradict a strict single-form-per-interval model. Mixed refuse, curated tablets and residual objects do not provide that test. |
| **Date or validity category:** the field records an issue period rather than amount | Independently dated production/usage episodes predict the category across multiple main strings; a proposed mapping must forecast new cases | No mapping or independent issue dates exist here. Published suggestions about currency/expiry are motivation, not decoded dates. Coarse Harappan phases cannot validate a proposed annual code. |
| **Damage or copying error:** different groups are accidental reductions/additions | Photographs or microscopy reveal erased, broken, unfilled or recut strokes; clean examples converge on one underlying form | No loss/doubt is marked for the triad in the reviewed drawings, weakening a claim that the catalogue itself records such damage. Original photographs are still needed; normalized drawings cannot exclude subtle damage. |

These predictions test restricted alternatives; rejecting one does not automatically prove quantity notation. A quantity system could also be mass-produced in lots or encoded on interchangeable molds. Conversely, a successful lot prediction need not eliminate quantity because a lot could contain one standardized denomination. The evidence must constrain more than the same graphic labels.

## Present conclusion and next decisive evidence

Follow-up: the [exact primary joins](M77_U_ARTIFACT_BRIDGE.md) requested below have
now been recovered for all three tablets, with photographs, material and find
context. Tooling and production groups remain unresolved. A separate
[frozen length prediction](M77_U_LENGTH_HOLDOUT.md) failed on additional examples;
physical tablet length is not a validated quantity calibration.

The defensible non-quantity competitor is a **separately varying categorical field associated with production or use**, with its categories still unknown. It is a candidate explanation, not a recovered meaning. Pure replication explains dependence among repeated references but does not explain why three complete stroke groups occur beside the same main text. Free allography and arbitrary category labels remain observationally permissive; neither deserves positive confirmation from these records alone.

The most useful next evidence is an exact primary object join for 4508/4509/4548, followed by photographs and independently recorded material, tooling and find context. Form production groups without using the auxiliary count, retain one representative per verified mold where appropriate, and then test the stated prediction on additional objects. Do not infer represented quantity from tablet size alone or infer independent transactions from the number of copies. The sorted pilot can support these concrete tests, but cannot rank semantic interpretations by itself.
