# Umma: recovered reproduction and a concrete library locator

28 September2026. A new request successfully retrieved the figure linked from
[Harappa's presentation of Frenez's review](https://www.harappa.com/content/indus-valley-early-commercial-connections-central-and-western-asia).
Panel D is credited to SAHI and captioned to the2017 Tell Jokha report, p59,
fig6.61. Parent inspection confirms a partial object with signs above a damaged
figural field in this reproduction. Panel E is a different, older Ashmolean
sealing. The two are kept separate.

This updates the earlier [audit](UMMA_ANCHOR_AUDIT.md), which accurately recorded
its unsuccessful retrievals and lack of visual inspection at that time. The
earlier audit is retained unchanged. The new response was HTTP200 and the
144,018byte image has SHA256
`5a44511b714c5c6d1c1301a3cd925749e5ae2aa5b4da08bcaad163a0e90918c0`.
The image is a published secondary reproduction, not the original excavation
report page. The independent [graphic review](UMMA_REPRODUCED_IMAGE_REVIEW.md)
records what the pixels can support.

The exact identifier TJ17-PRO-S56, proposed PRO/S expansions, alleged original
orientation and seal-versus-impression wording remain unverified against the
primary report. The two June2026 Reddit posts repeat the same claim; they do not
provide independent corroboration. We have neither rotated nor mirrored the
figure to infer the original sign order. No numerical sign transcription or
word/sound value is assigned from this small reproduction.

Five exact searches were run: `"TJ17-PRO-S56"`,
`"978-80-89704-05-7" pdf`, `SAHI Tell Jokha 2017 report seal 59 Hulinek`,
`SAHI Tell Jokha 2017 filetype:pdf`, and `Tell Jokha Harappan seal S56`.
Subsequent opens followed relevant returned records and the displayed figure
link. Search/open responses are preserved as typed tool captures in data/raw;
they are not original HTTP pages.

The indexed [official Slovak library catalogue](https://sclib.svkk.sk/sck01test/Record/000596329)
supplies ISBN978-80-89704-05-7 and call number V.237993, reports79 numbered plus190
unnumbered pages, and advertises a limited scan-request service. Direct opening
through the web tool returned an Internal Error, so this remains indexed
catalogue evidence, not inspection of the book. Other library and publisher
records disagree on2017/2018 dating and page count. No pagination offset is
inferred, and no scan request has been submitted.

The newly surfaced [University of Geneva PDF](https://www.unige.ch/lettres/antic/download_file/view/1214/589)
is a two-page programme for6July2019 talks, including the SAHI project and new
administrative documents. It supplies no object entry. Its recent search date
does not make it a new excavation publication. An unrelated CDLI Umma tablet is
also not a bilingual merely because it comes from the same city.

The [structured record](../data/processed/umma_renewed_search.json) and
[persistence script](../scripts/persist_umma_renewed_search.py) preserve queries,
failures, source classes and hashes. The useful change is an inspectable image
and a concrete report holding. There is still no authenticated same-object
connection to a known name, count, commodity or parallel readable text.
