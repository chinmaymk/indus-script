## Same other-side text, different stroke group

An additional, independently viewed comparison with the parent's adjacent-page pilot confirms a concrete variation witness:

| Reference | Primary location | Side 1, line 0 | Side 2, line 0 |
|---|---|---|---|
| 5464 | Printed 568/PDF 579, entry 1 | `M048 M342 M176` | `M087 M328` — two long strokes |
| 4387 | Printed 573/PDF 584, entry 9 | `M048 M342 M176` | `M089 M328` — three long strokes |

Both references and both side lines were inspected together in dedicated crops. The shared bent figure is M048, not the distinct bird-like M076. The three-stroke group matches primary M089. No doubt or loss mark is visible in these paired lines. The same three-sign main pattern with the three-stroke side is also visibly repeated for 4403, 4405, 4509, 4543, 4575, 5407 and 5409 on PDF 584. Those adjacent-page records are **not** added to this review's 46-row total.

This establishes that the exact normalized other-side sequence alone does not determine the stroke group: the same text accompanies two different groups. It supports testing the stroke-plus-M328 line as a separately varying field. It does not establish a numerical unit, commodity, phonetic value or translation. The comparison was suggested after source inspection and is exploratory, not a held-out prediction; different reference numbers are not automatically statistically independent observations.

## Scope and verification

Full-page renders use the unique prefix `results/primary_pages/structure-u-pilot`. Detail images preserve the two longer lines, the loss and doubtful examples, and both sides of 5464/4387. Primary Sign List pages 32–35 authenticated the assigned glyph forms. Thirty selected references also have confidently legible other-side sequences transcribed in the ledger (34 context lines). Remaining contextual drawings stay available in the full-page images without invented IDs or substitution from the canonical export.

The concordance groups similar environments, so the 46/46 local association is a descriptive count from selected pages, not an unbiased prevalence estimate or a significance test. No semantic readings, source-data changes, or assumption that canonical exports always retain the first side were made. The parent performs the canonical join. This review claims completeness only for the indexed M328 lines on its three assigned pages; integration with other pilot pages must preserve source references and avoid duplicate counting.
