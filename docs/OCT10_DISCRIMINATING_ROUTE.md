## New primary acquisitions and results

The parent supplied [Aurore Didier’s official ArScAn publication profile](https://arscan.parisnanterre.fr/membre/aurore-didier/). Four exact-ID searches and public HAL API metadata queries resolved seven records. Direct web opens of HAL returned internal errors; the public API and its explicit PDF links succeeded. A first sandboxed network attempt failed DNS without response bytes; the authorized ordinary network fetch succeeded. The initial exploratory web open was not saved in full; the retained capture includes repeated opens and the four-query search. These are recorded rather than counted as new independent evidence.

- **Poster11, excavations2019–2022:** [original PDF](https://shs.hal.science/halshs-05431314/file/PosterMAFBI_11.pdf), PDF2, reports7 or more MoundII blocks,6,500m², contextualized production remains and a few steatite seals among more than80,000 objects. The plan distinguishes operations and materials. Its proposal that much of the city specialized in lapidary work warns against treating generic site-wide seal occurrence as commodity-specific evidence. It does not list individual seal IDs, texts or their room/deposit joins. It does photograph two inscribed seal faces, one fragmentary. The original embedded image I22.jpg (537×311) was extracted without resampling and inspected; it is saved as `results/oct10_route_poster11_seals.jpg`. The parent is comparing the earlier2017 photograph before treating either as an independent new specimen. No catalogue sign codes are assigned here.
- **Poster13, excavations2023–2024:** [original PDF](https://hal.science/hal-05434452/file/PosterMAFBI_13.pdf), PDF2, identifies Trench6 steatite manufacture and a hidden pot containing a119-bead necklace, an incised steatite button, and12–15,000 microbeads. It also reports7,151 chips and1,037 preforms/beads from the workshop. These counted collections have no authenticated corresponding Indus inscription in the poster. Seals and weights are reported in the later Trench4 floor discussion; they must not silently move into Trench6’s earlier workshop. The illustrated geometric stamp has no separate linear inscription visible at the reviewed poster resolution, and no object ID is printed beside it.
- **2026 specialized-workshop communication, hal-05691442:** the official API abstract distinguishes Trench6-East steatite manufacture in MoundI from the earlier-excavated multimaterial MoundII complex. No attached file fields were returned. This is an abstract-level description, not an independently reviewed full report.
- **2024 final report, halshs-05523662, and activity report, hal-04869704:** official metadata records were recovered, without attached file fields in the queried response. This does not prove that copies are unavailable everywhere.
- **2017 article, halshs-02978545:** the API exposed an explicit PDF link; it was passed to the parent for acquisition, avoiding duplicate downloads. **2023 proceedings, halshs-04365872:** no attached file fields were returned. The parent owns those earlier sources.

The useful next discrimination is finite: join the new seals to context IDs and sign sequences, then compare the frozen fish indicator and rival signs across independently classified production deposits. Dedicated steatite versus multimaterial areas could sharpen a domain hypothesis if texts and comparable observation opportunities can actually be recovered. No effect size or translation can be computed from the current poster-level reporting. The existence of a count119 does not license assigning that number to an untranscribed button or vessel.

This is provenance and accounting, not independent validation of ancient meanings. All417 semantic and phonetic fields remain null. No outreach, archive request or speculative assignment was made. The complete decipherment remains unresolved, with a concrete new source series now replacing the earlier inference that the retained-route list was the only useful next action.
