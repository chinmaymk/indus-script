# Download archive

All downloaded research files are stored in this folder. Source URLs, revisions,
hashes, and usage notes are recorded in `../sources.json`.

The inscription CSV and two corpus archives supply the analysis. Repository trees,
the official site's HTML/JavaScript, and the unused `lipi` transliteration table are
preserved for provenance only. The access-denied JSON records the unsuccessful
official-data request; it is not inscription data and is never retried by the pipeline.

Primary catalogue and research PDFs added later support the documented source
audits. Their interpretations are not automatically accepted sign readings.
`mayig_LICENSE` was extracted from the registered corpus archive; this README was
written locally. Neither is a separate download. Future downloads belong here.
